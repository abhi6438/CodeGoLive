WHAT WE ARE BUILDING
OVERVIEW
Goal: Take the Arena mockup (HTML demos) and implement every feature as real working code in the CodeGoLive codebase — backed by a Supabase database, FastAPI scoring engine, and Supabase Realtime multiplayer. Users should be able to challenge each other, battle in live quiz rooms, earn XP + AP, spin the wheel, climb leaderboards, and unlock achievements.
⚔️Live Multiplayer Matches

Real-time 1v1 and team battles via Supabase Realtime channels. Both players see the same question at the same time.

⚡Scoring Engine

Time-based XP/AP multipliers (5× to 0.5×) stacked with combo chain bonuses. Server-side validated.

💬In-Match Social

Live chat, emoji reactions, and provoke taunts sent to opponent during a match — all via Realtime.

📋Quest System

Daily + weekly quests that auto-generate, track progress, and pay out AP + XP on claim.

🏆Achievements

12 badge types with unlock conditions. Trigger on match end, quest claim, or streak milestones.

🎰Spin Wheel

One free spin per day. Extra spins cost 50 AP. Weighted prizes including jackpot. Backend logs every spin.

FASTAPI ENDPOINTS
BACKEND

All routes prefixed /api/arena/. Auth via Supabase JWT. Scoring calculations happen server-side so clients cannot cheat.

POST
/api/arena/match/create
Create a match room. Returns room_code. Inserts into arena_matches with status=waiting.
POST
/api/arena/match/join
Join a match by room_code. Sets opponent_id, status→active. Broadcasts start event to Realtime channel.
POST
/api/arena/match/answer
Submit an answer. Body: match_id, question_index, answer, client_time_remaining. Server calculates multiplier + combo, updates arena_match_players.score, returns earned XP/AP.
GET
/api/arena/match/{id}/result
Return final scores, winner, XP/AP earned, achievements unlocked in that match.
POST
/api/arena/challenge/send
Send a challenge invite to a user (by user_id or email). Creates arena_challenges record, triggers notification.
POST
/api/arena/challenge/respond
Accept or decline a challenge. If accepted, auto-creates a match room and returns room_code.
POST
/api/arena/team/create
Create a new team with name + badge emoji. Owner auto-added as first member.
POST
/api/arena/team/invite
Invite a user to your team. Sends notification; user accepts/declines in lobby.
GET
/api/arena/quests/me
Return current user's daily and weekly quests with progress. Auto-generates quests if none exist for today/this week.
POST
/api/arena/quests/claim
Claim a completed quest. Awards XP + AP, marks claimed_at. Idempotent.
GET
/api/arena/achievements/me
Return all achievements the user has unlocked.
GET
/api/arena/leaderboard/weekly
Top 100 for current week. Includes prize pool calculation (2% of all XP this week).
POST
/api/arena/spin
Spin the wheel. Checks daily free spin or deducts 50 AP. Server picks weighted prize. Logs to arena_spin_log, credits reward.
WS
Supabase Realtime channels (not REST)
Channel per match: arena:match:{id}. Broadcasts: question_start, answer_reveal, chat, reaction, taunt, match_end. Client subscribes on join, unsubscribes on leave.

SCORING ENGINE LOGIC
SERVER-SIDE
ANSWER WINDOW TIER XP MULT AP MULT BASE XP MAX XP
0 – 3 s⚡ LIGHTNING5×5×20100
3 – 6 s🎯 SWIFT3×3×2060
6 – 12 s✓ SHARP2×2×2040
12 – 22 sSTEADY1×1×2020
22 – 30 s🐢 SLOW0.5×0.5×2010
timeout✗ MISS00—0
Combo Chain Bonus

3 correct in a row → 🔥 CHAIN · +1.5× multiplier on XP + AP

5+ correct in a row → ⚡ INFERNO · +2× multiplier

Wrong answer or timeout resets combo to 0.

Final Formula

xp = base_xp × time_mult × combo_mult
ap = base_ap × time_mult × combo_mult

Both calculated server-side on /api/arena/match/answer

Anti-cheat: The client sends time_remaining from its local timer, but the server also stores question_sent_at for each match. If client-reported time differs from server time by more than 2 seconds, the server uses its own calculation. Clients cannot claim a 5× multiplier by lying.

REAL-TIME ARCHITECTURE
SUPABASE REALTIME
One channel per match: arena:match:{matchId}. Both players subscribe on join and unsubscribe on leave/disconnect.
EVENT TYPEDIRECTIONPAYLOAD
question_startServer → Both{ question, options, time_limit, sent_at }
answer_revealServer → Both{ correct_index, player_scores }
score_updateServer → Both{ user_id, score, xp, ap, combo }
chatPlayer → Both{ from_user, text, created_at }
reactionPlayer → Both{ from_user, emoji }
tauntPlayer → Opponent{ from_user, taunt_text }
match_endServer → Both{ winner_id, final_scores, rewards }
opponent_leftServer → Remaining{ user_id, reason: disconnect|timeout }
Presence: Is Opponent Still There?

Use Supabase Realtime Presence to track whether both players are connected. If one disconnects for more than 30 seconds, the server auto-ends the match and awards the win to the remaining player.
